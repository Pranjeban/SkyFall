## 2. Release document summaries

### 2.1 v0.9.2 — "Account, Session, and Workspace Refinement" [V]

Intent: remove blockers to v1 — stable Power Platform connection, saved Microsoft accounts, clearer session management, calmer visual system. Explicitly **kept at v0.9.2**; v1 gated on UX/workflow issues.

- Power Platform: no PAC CLI in active flows; desktop sign-in reuses Azure CLI browser login in a named isolated SKYFALL profile; no client ID entered; Azure CLI owns the per-profile token cache; environment selection persists per profile; environment discovery via Power Apps environments API with short-lived token for `https://service.powerapps.com/`; flow inventory via Dataverse Web API, metadata only, solution cloud flows only (My Flows unsupported); short-lived token per selected environment. (`R:9-14,50-52`)
- UI/session: professional slate palette; independently scrollable navigation; anchored floating assistant/local session controls; local conversation deletion; selecting an account no longer routes through "Manage". (`R:18-22`)
- Diagnostics: stable error codes and actionable 401/403/not-found/throttling guidance; pagination follows only HTTPS links on expected Microsoft host. (`R:26-28`)
- Tests/tooling: 20 total tools, 4 Power Platform discovery tools (`R:48`); 12 focused Power Platform account/auth tests pass; MCP smoke test cannot run in workspace (missing `mcp`/`httpx`); capability counts and client-ID regex fixed; Azure MCP login import restored with test-mode guard. (`R:38-48,66-70`)
- Visual: Kiro-inspired rounded shell, searchable session list, eased scrolling, then `Design.md` refinement (near-black graphite/plum, muted violet, hairline borders, 10/14/18/24 px radii). (`R:54-64`)
- **Verification limits:** syntax compilation + `git diff --check` only; full suite and desktop visual QA not run; Python environment lacks PySide6. (`R:30-32,58,64`)

### 2.2 v1.0 — "Intelligent Engineering Orchestration" [V]

Status: **"active milestone definition / preview work"**; app version remains 0.9.2 until v1.0 gates complete. (`V1:3`)

- Product goal: 10 visible stages — search approved workspaces; resolve one script; inspect permitted metadata; resolve exact environment (never guess QA/PROD); validate identity; build plan; explicit approval; controlled executor; validate exit status/artifacts; deliver report path. (`V1:7-18`)
- Preview implemented: Execution placeholder replaced by task-first Execution Center; local metadata search for indexed scripts (no source shown/displayed); explicit account/tenant/environment context with no tokens shown; 10 labeled stages, persistent progress bar, explicit approval, confirmed **read-only** Flow Inventory run route; theme toward light stone/slate/blue-teal. (`V1:22-27`)
- Explicit limitation: the first wired route **does not execute the matched workspace script**; arbitrary script execution still requires a purpose-built security boundary and validator. (`V1:26`)
- Security gates before release: no silent environment/profile changes; never show tokens/secrets; explicit approval for script runs/cloud changes; constrained allowlist; verify workspace approval, path containment, indexed hash/freshness, parameters, dependencies, timeout, cancellation, output location, report validation; Python/PowerShell subprocess under user account is **not** a sandbox. (`V1:29-36`)
- Verification required: full regression suite; account refresh, ambiguous environment, expired auth, denial, cancellation, partial errors, report validation/recovery; visual QA at normal/compact sizes; **do not label v1.0 released** until gates and controlled execution path complete. (`V1:46-51`)
- Visual direction: first light slate redesign rejected by user; replacement uses Kiro Crew screenshot (near-black graphite/plum, lavender navigation, violet focus, layered translucent cards, mint/amber status). Visual validation still pending. (`V1:54-58`)
