## How to run tests manually

PowerShell:
```
.\scripts\run_tests.ps1
.\scripts\run_tests.ps1 tests/unit -v
```

Python:
```
python scripts/run_tests.py
python scripts/run_tests.py tests/unit -v
```

Direct:
```
.\venv_skyfall\Scripts\python.exe -m pytest tests/ -q
```

## Gitignore notes

`.gitignore` line changed from `.venv/` to `.venv*/`. All other lines preserved.

## Naming convention

- In-repo venvs use the `venv_<purpose>/` prefix (e.g. `venv_skyfall`).
- Legacy `.venv*` directories are still ignored for backwards compatibility.
- `.gitignore` ignores both `venv_*/` and `.venv*/`.

## Troubleshooting

- If `venv_skyfall\Scripts\python.exe` is missing, recreate: `py -3.11 -m venv venv_skyfall`.
- If pytest not found, install: `venv_skyfall\Scripts\python.exe -m pip install pytest`.
- Do not use the broken `.venv`.
